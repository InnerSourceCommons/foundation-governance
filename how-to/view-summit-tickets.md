# How to See Summit Ticket Sales in Pretix

InnerSource Commons sells InnerSource Summit tickets through Pretix.
You can open the Foundation's Pretix account to see orders, ticket types, and running totals without asking anyone for a report.
Pretix uses one shared login, so you also need to be on its email alias.
For how shared logins work, see [How We Run Shared Logins](shared-logins).

## Get access and sign in

Follow [How We Run Shared Logins](shared-logins) for the `pretix@innersourcecommons.org` alias and the Pretix credentials sheet.
Then sign in at the [Pretix control panel](https://pretix.eu/control/).

## Find the ticket numbers

1. Open the **InnerSource Commons** organizer, then the **InnerSource Summit 2026** event.
2. The event dashboard shows the running totals.
3. **Orders** lists every order with its status and ticket type.

Eventbrite registrations are separate and use their own shared login; see [How We Run Shared Logins](shared-logins).
